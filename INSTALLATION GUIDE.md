# INSTALL INSTRUCTIONS

## Download/Extract Zip folder.

## Open Folder "A"
- Run `.exe` file to install "Input-Overlay" plugin into OBS

## Open Folder "B"
- Copy the Folder Inside the "B" folder("Controller Overlay NIXSTAH") and paste it into the same location you have your custom OBS overlays saved.

## Open OBS
- Navigate to Desired Scene
- Click `+` to Add New Source
- Select `Input-Overlay`
- When prompted in dialog box, click browse and navigate to the folder you saved/pasted with your other custom OBS overlays and select the only `.png` file available. Do the same for the field below it except you are now going to select the only `.json` file available from that same folder. 

-![alt text](image.png)

#  That's it! Move the controller around as you please. 

> [!TIP]
> There is an additional `Input Overlay` settings menu under the **Tools** menu at the top of OBS window.
